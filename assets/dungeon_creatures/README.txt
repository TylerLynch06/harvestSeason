LOW-POLY DUNGEON KIT — FREE STARTER  ·  by Woshi Gang Studio
============================================================
A free taste of the Low-Poly Dungeon Kit. Stylised low-poly 3D,
game-ready for Godot / Unity / Unreal.

============================ WHAT'S IN THE FREE PACK ============================
CHARACTERS (5):
  Warrior — 16 animation clips (idle/walk/jog/sprint/sword attack/death/roll/jump/+)
  Villager — 16 animation clips, same shared 65-bone rig
  Skeleton — 16 animation clips, same shared rig
  Slime — custom squash-bounce rig
  Giant Rat — NEW! custom rig, idle/walk/death clips
ENVIRONMENT (20): walls, floors, stairs, column, barrel, crate, chest, torch
  + NEW GOODIES: Mimic Chest, Fountain, Knight Statue
WEAPONS (3): sword, axe, staff
UI (8): health/mana orbs, bars, hotbar, slots

============================ FORMATS ============================
  Characters : animated .glb (all clips baked in)
  Environment/weapons : .glb with embedded materials
  UI : .png

============================ USE (Godot) ============================
  - Drag the .glb into your project — materials import as StandardMaterial3D;
    character clips import as named animations. Set locomotion clips to LOOP.
  - 1 unit = 1 m. Environment snaps on a 1-unit grid.
